# Suwayomi

Use the official `ghcr.io/suwayomi/suwayomi-server:stable` image. The documented container listens on port 4567. Mount a Volume for the server data/downloads path according to the upstream container repository, and configure the server through its supported variables/settings. Verify the exact mount path against the image release before production use.

Official image source: https://github.com/Suwayomi/Suwayomi-Server-docker
