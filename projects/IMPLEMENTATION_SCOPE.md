# Implementation scope

Railway-ready Docker service definitions were added for SearXNG, Reactive Resume, changedetection.io, Suwayomi, LibreTranslate, ArchiveBox, and Vaultwarden.

Cobalt, gallery-dl, AutoResearch, video-use, Agent-Reach, and free-claude-code remain source/configuration dependent and are documented but not given fabricated containers. LocalSend is excluded because Railway cannot provide local-network discovery. VODER remains on Kaggle/GPU. Google Cloud and Oracle Cloud are deployment targets, not applications.
